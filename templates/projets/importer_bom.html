📥 Importer une nomenclature (BOM) depuis Excel

Le fichier doit contenir les colonnes: ParentItem, ChildItem, NAME, BOMQTY, UNITID, Level
Annuler
ℹ️ Format du fichier Excel
Colonnes requises:
  • ParentItem: Code du produit parent
  • ChildItem: Code du composant enfant
  • NAME: Nom/désignation du produit
  • BOMQTY: Quantité nécessaire
  • UNITID: Unité de mesure (EA, Pcs, sq ft, m2, etc.)
  • Level: Niveau dans la nomenclature (1, 2, etc.)
Exemple de structure:
ParentItem ChildItem BOMQTY Level
M505110 M308000 1 1
M505110 AV003253 100 1
M505110 M206100 1 2
⚠️ Important:
  • Les produits finis sont détectés automatiquement (ParentItem de niveau 1)
  • Les PSF sont détectés si un ChildItem apparaît aussi comme ParentItem
  • Les matières premières sont les ChildItem qui ne sont jamais ParentItem
